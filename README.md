# Personal Portfolio Website

Portfolio of Arpon Kumar Sarkar Sumit, CSE student at IUBAT, Dhaka.

A dynamic site built with plain HTML, CSS and JavaScript. No build step, no dependencies.

## Features
- Content rendered by JavaScript from one data file (`data.js`)
- Light and dark theme, remembered between visits
- Animated ultrasound hero, typing roles, animated counters, scroll progress bar
- Project filter and detail pop-up
- Contact form with validation
- Responsive layout, keyboard focus styles, reduced-motion support

## Edit the content
Change only `data.js`. Replace the email placeholder and check the project repository links.

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
Settings > Pages > Deploy from branch `main` / root.

## Files
- `index.html` page shell
- `data.js` all content
- `style.css` styles and themes
- `script.js` rendering and interactions
